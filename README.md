# Proyecto ALKIRA

Plataforma inteligente para la administración de inmuebles y condominios.

---

## Estructura del Repositorio

Para evitar conflictos entre las distintas tecnologías, el código se divide en tres directorios principales:

* **`/movil`:** Contiene el proyecto de Android Studio para la aplicación móvil de los inquilinos.
* **`/pwa`:** Contiene el código de la plataforma web para los administradores.
* **`/backend`:** Contiene el desarrollo de la API y la conexión a la base de datos.
